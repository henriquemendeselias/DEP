# Estudos em Business Intelligence (Power BI)

Este diretório é dedicado ao acompanhamento, anotações e projetos práticos do curso de Power BI do instrutor João Paulo de Lira na Udemy.

---

## 🎯 Objetivo
Dominar a criação de soluções completas de BI, desde a ingestão e tratamento de dados até a modelagem dimensional, cálculos com DAX e construção de relatórios analíticos interativos.

## 📌 Boas Práticas Adotadas

1. **Demonstração Visual:** Sempre incluir prints dos dashboards no README de cada relatório para facilitar a visualização no GitHub sem precisar abrir o Power BI Desktop.
2. **Versionamento Leve:** Priorizar salvar modelos como `.pbit` (templates) ou `.pbip` (Power BI Project), mantendo os arquivos leves no repositório.
3. **Fórmulas Documentadas:** Guardar as principais medidas DAX em arquivos de texto/markdown para consulta rápida.
